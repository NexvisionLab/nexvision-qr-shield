# NexVision QR Shield v4.0.0

Released: 22 September 2026

Version 4.0 adds an advanced, layered detection architecture while retaining a fully offline default and no professional or external API dependency.

## Advanced detection added

- Recursive percent, HTML-entity, JSON-escape and Base64 decoding with strict resource budgets.
- Hidden URL, concealed dangerous-scheme, multi-stage encoding and disguised security-term detection.
- Cross-field brand/domain mismatch, shared-host authentication lure, fragment lure, encoded delimiter and double-extension detection.
- Four-stage attack-chain fusion across concealment, impersonation, pressure and sensitive actions.
- WalletConnect session classification with symmetric-key redaction.
- EPC/SEPA payment QR parsing, amount validation and IBAN mod-97 checking.
- Email/SMS CRLF injection and incomplete enterprise Wi-Fi validation warnings.
- Additional QR structural evidence: dark-module density, timing alternation and central overlay indicator.
- Advanced evidence panel in the web UI and standalone HTML report.

## Safety and interpretation

- Decoded intermediate bodies are not stored; reports contain hashes, lengths, transformations and privacy-safe URLs.
- Shared hosting, tunnels and QR structure are contextual evidence only—not reputation decisions.
- Structural QR research was not converted into an unvalidated maliciousness probability.
- Existing multilingual, privacy, SSRF, payment, image and grouped-scoring controls remain active.

## Validation

- 128 automated tests pass, including 28 new v4 adversarial, budget and benign regression tests.
- No runtime reputation, translation, WHOIS, RDAP, cloud AI or telemetry API was added.
